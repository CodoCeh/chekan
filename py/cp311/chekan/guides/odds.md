# Коэффициенты и результаты спорта

## Что это и когда брать

Сайт football-data.co.uk бесплатно отдаёт CSV по футбольным лигам: результаты матчей и коэффициенты букмекеров на открытии и на закрытии (последняя цена перед стартом). По ним считают вероятность из коэффициента, маржу букмекера (его встроенную наценку), ценность ставки (value, когда твоя вероятность выше рыночной) и CLV (closing line value — насколько твой коэффициент лучше справедливого коэффициента закрытия). Бери для анализа рынка и проверки модели прогнозов на истории.

Не бери для живых коэффициентов прямо сейчас: файлы обновляются раз в несколько дней. Роль делает только анализ и бумажные (виртуальные) ставки. Реальные ставки, пополнение счёта у букмекера и переводы денег делает только человек сам.

## Установка и проверка

```bash
uv run -q --with pandas python -c "import pandas; print('pandas', pandas.__version__)"
```

`uv run --with` ставит pandas временно и без следа. Если нет `uv`, спроси пользователя и ставь только после его «да».

## Порядок работы

1. Скачай сезон: `mmz4281/<сезон>/<лига>.csv`, где сезон `2425` — это 2024/25, `E0` — английская Премьер-лига. Сайт перенаправляет запрос, поэтому `curl -L`.
2. Читай CSV с `encoding="utf-8-sig"`: в начале файла стоит BOM (служебный невидимый символ).
3. Вероятность из коэффициента: `p = 1 / k`. Сумма по трём исходам больше 1. Излишек — маржа.
4. Сними маржу: пропорционально (`p_i / сумма`) или методом Шина. Пропорциональный метод занижает фаворитов, учитывай это.
5. Эталон справедливой цены — закрытие Pinnacle (`PSCH/PSCD/PSCA`), у него маржа ниже всех.
6. Ценность: `EV = k * p_модели - 1`. CLV: `k_взятый * p_закрытия_справедливая - 1`.
7. Оценивай на сотнях ставок, а не на десятке.

## Готовые команды

Скачать сезон и проверить столбцы закрытия:

```bash
mkdir -p results && curl -sL -o results/E0_2425.csv "https://www.football-data.co.uk/mmz4281/2425/E0.csv"
head -1 results/E0_2425.csv | tr ',' '\n' | grep -E "^(PS|B365|Avg|Max)C[HDA]$" | tr '\n' ' '; echo
```

Маржа, точность вероятностей, ROI и CLV на сезоне:

```bash
cat > odds_margin.py <<'EOF'
import sys
import pandas as pd
df = pd.read_csv(sys.argv[1], encoding="utf-8-sig").dropna(subset=["PSCH", "B365H"])
def implied(df, p):
    return 1 / df[[p + "H", p + "D", p + "A"]].to_numpy()
for p, name in [("B365", "Bet365 открытие"), ("B365C", "Bet365 закрытие"),
                ("PSC", "Pinnacle закрытие"), ("MaxC", "лучшая цена рынка, закрытие")]:
    print(f"{name:30} маржа {(implied(df, p).sum(axis=1) - 1).mean()*100:5.2f}%")
ip = implied(df, "PSC")
fair = ip / ip.sum(axis=1, keepdims=True)
won = pd.get_dummies(df.FTR).reindex(columns=["H", "D", "A"]).to_numpy(float)
print(f"Брайер справедливых вероятностей Pinnacle: {((fair - won) ** 2).sum(axis=1).mean():.4f}")
taken = df[["B365H", "B365D", "B365A"]].to_numpy()
clv = taken * fair - 1
pos = clv > 0
pnl = (taken - 1) * won - (1 - won)
print(f"Все исходы по Bet365 открытия: {pnl.size} шт, ROI {pnl.mean()*100:5.2f}%, CLV {clv.mean()*100:5.2f}%")
print(f"Только CLV>0: {pos.sum()} шт, ROI {pnl[pos].mean()*100:5.2f}%, CLV {clv[pos].mean()*100:5.2f}%")
EOF
uv run -q --with pandas python -I odds_margin.py results/E0_2425.csv | tee results/odds_margin.txt
```

На сезоне 2024/25 вышло: маржа Bet365 около 5,5%, Pinnacle на закрытии около 3%. Ставки на все исходы подряд дают ROI около −6%, то есть ровно минус маржа. Ставки с положительным CLV на одном сезоне (216 штук) всё равно ушли в минус: выборка мала, разброс велик.

Ценность одной ставки:

```bash
python3 -c "k=2.10; p=0.50; print('EV на 1 ед.: %+.3f' % (k*p-1))"
```

## Частые ошибки

- Читают CSV без `utf-8-sig`, и первый столбец называется `﻿Div`.
- Качают без `-L` и получают пустой файл после перенаправления 302.
- Берут вероятность `1/k` без снятия маржи и видят «ценность» там, где её нет.
- Отбирают ставки по коэффициенту закрытия. Закрытие известно только после ставки, это заглядывание в будущее. CLV — оценка качества, а не правило отбора.
- Делают вывод по 50–200 ставкам. Прибыль на такой выборке почти всегда шум. CLV сходится быстрее ROI, смотри на него.
- Берут `Max`-коэффициенты как доступные. Лучшая цена по рынку собрана из разных контор и часто недостижима.
- Не проверяют пропуски: в части матчей нет коэффициентов отдельных контор. Отбрасывай строки явно и пиши, сколько выкинул.
